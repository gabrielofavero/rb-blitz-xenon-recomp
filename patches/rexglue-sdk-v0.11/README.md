# ReXGlue v0.11.0 production stack and migration ledger

Status: registered production stack, 2026-11-18. **65 SDK patches** apply to exact
upstream v0.11.0 commit `a3e1d82678ca20d68d4837a8e9ee4652ff073745`.
The production gitlink and title integration now use this release and patch set.
The fresh Windows AMD64 production source-SDK release build passes.
Formal performance and native-platform/package gates remain open after adoption.
The [historical 71-patch baseline](../README.md) at
`c94f5ebdcb3c9d1a460ca48e04f9758448f8d518`, including its nested MoltenVK patch,
is retained for rollback. The
[migration plan](../../docs/plans/in-progress/2026-11-17-rexglue-v0.11-migration-plan.md)
owns current delivery gates and validation.

The ledger covers all **71 original SDK patch IDs**, the retained nested
MoltenVK patch, and new responsibilities **0089**, **0090**, **0091**, **0092** and **0093**. Sixty original IDs have candidate
files; eleven use an upstream/title replacement or fold into an owning candidate.
Original IDs retain their responsibility even when filenames or implementation
layers change. Corrections are folded into the owning candidate; 0089 is separate
because filesystem provider composition is distinct from validation and residency.
0090 separately fixes modular workspace interface lifetime across image selection
and reload, preserving the upstream heap-flag decoding that replaces original 0007.
0091 separately rolls back a failed modular graphics attach before the kernel waits
for title-context borrowers; 0021 retains preparation lifecycle ownership.
0092 independently synchronizes upstream shutdown-test launch readiness; it changes
no production behavior or runtime timeout.
0093 separately orders write publication after queued ring setup and retires the
previous pointer while preserving nonblocking memory-wait callers; 0018 retains
malformed-packet recovery.
No removed SDK API shim or second runtime is introduced.

The ignored validation prototype is `out/rexglue-migration/worktree/`; its title
integration is now promoted. `src/` paths below describe the title or, for SDK
internals, `rexglue-sdk/`. Historical candidate links identify the exact
implementation and regression sources used for each recorded checkpoint.
Shared scope means applicable Windows, Linux, macOS and iOS paths, with existing
architecture/backend guards preserved. D3D12 is Windows-specific; Vulkan uses
MoltenVK on supported Apple routes. Windows amd64 evidence does not establish
Windows ARM64, native Linux, macOS, iOS, Retina or MoltenVK correctness.

## Public title lifecycle replacement

The title now uses `rex::app::TitleApp` and public modular services. Native restart
bootstrap and iOS importer preflight precede `Init`; configuration/settings/UI
hooks run at their public lifecycle boundaries. `OnTitleLaunch` installs required
payload/services and rejects failure before guest launch. `OnTitleStopping` closes
content-progress, probe, display-trial and reader workers before unmap; retained
asset/provider lifetimes are released after guest unload. `Shutdown` is idempotent.
Incomplete `OnInit` performs explicit rollback because SDK OnShutdown is called
only after OnInit completed. SDK title stop/unload precedes OnShutdown while
services are still available. This source call-order audit replaces 0030/0079
mechanisms; native importer/relaunch/failure captures remain open.
