# Cancelled plans

Plans that were written, then abandoned or superseded before delivery. They are kept — not deleted —
because the reason they were dropped is usually the expensive part: it names the measurement or the
runtime limit that made the route a dead end, and that is exactly what stops someone walking it
again. A superseded plan carries a note at the top saying what replaced it.
